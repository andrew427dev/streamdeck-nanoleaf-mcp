# v0.6.0-beta.3 — candidate, not published

Prepared on **2026-10-26** as a **Mac beta / Windows 11 x64 experimental beta** candidate. Package version `0.6.0-beta.3` maps to Stream Deck manifest `0.6.0.3`. This is distinct from the old private `v0.5.0-beta.3` mirror experiment.

## Included changes

- Relaunch Desktop after a successful automatic start followed by a quick app exit. Preserve valid concurrent waiters, the original discovery deadline and cancellation of unsent inputs; reuse successful connection probes.
- Separate each request's wait limit from shared MCP initialization. A short first request no longer cancels another request with time remaining. Shared initialization still has a bounded timeout and expired callers never send their tool commands.
- Explain in English and Korean that a timed-out command may already have changed the light; check its actual state before pressing again. Uncertain mutations are never automatically replayed.
- Retain SDK 3.0.2 and apply a compatibility-tested Zod 4.6.7 override only under `@elgato/utils`. Update build-only fast-uri to 3.1.9. Add actual SDK schema and bounded-array security regressions.
- Gate Mac/Windows CI on a locked dependency-security check, with manual execution and weekly advisory checks configured. The verification branch does not activate the scheduled workflow on `main`.

## Preserved state and remaining gates

The working Mac installation and public downloads remain **v0.6.0-beta.2**. Existing profiles, buttons, dials, titles, app-launch preferences, Desktop and saved scenes are preserved. No new physical-device test is claimed; prior beta.2 Mac checks and the Windows physical-button report stay attributed to that version.
