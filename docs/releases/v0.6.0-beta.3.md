# v0.6.0-beta.3 — Mac beta / Windows experimental beta

Prepared on **2026-10-26**, installed/tested separately on Mac that day, and approved for publication on **2026-10-28** as a **Mac beta / Windows 11 x64 experimental beta**. Package version `0.6.0-beta.3` maps to Stream Deck manifest `0.6.0.3`. This is distinct from the old private `v0.5.0-beta.3` mirror experiment.

## Included changes

- Relaunch Desktop after a successful automatic start followed by a quick app exit. Preserve valid concurrent waiters, the original discovery deadline and cancellation of unsent inputs; reuse successful connection probes.
- Separate each request's wait limit from shared MCP initialization. A short first request no longer cancels another request with time remaining. Shared initialization still has a bounded timeout and expired callers never send their tool commands.
- Explain in English and Korean that a timed-out command may already have changed the light; check its actual state before pressing again. Uncertain mutations are never automatically replayed.
- Retain SDK 3.0.2 and apply a compatibility-tested Zod 4.6.7 override only under `@elgato/utils`. Update build-only fast-uri to 3.1.9. Add actual SDK schema and bounded-array security regressions.
- Gate Mac/Windows CI on a locked dependency-security check, with manual execution and weekly advisory checks configured. The weekly advisory schedule is enabled when this workflow reaches `main`; candidate-branch checks alone did not enable it.

## Preserved state and remaining gates

Direct image inspection of local and Windows CI ON/OFF/unknown-state assets found no missing text, clipping or layout change. The small raster differences are observed build-host differences; no particular font version is claimed as their proven cause. Documentation-only evidence follow-ups do not replace or rebuild the local candidate pair.

At preparation time, the working Mac installation and public downloads remained **v0.6.0-beta.2**. Later on 2026-10-26, the maintainer separately authorized installing this Mac candidate: the installation became **v0.6.0-beta.3 / 0.6.0.3**, while downloads were still beta.2 at that time. All 50 installed files match the retained candidate; all 32 profile files remained byte-identical throughout installation and physical checks. The tester confirmed existing power/scene/brightness keys and one scene-key automatic launch after Desktop was fully quit. Readback confirmed the app/device connection and unchanged saved-scene list. See [installation validation](../VALIDATION.md). Wider Mac and all beta.3 Windows hardware acceptance remain pending; prior beta.2 reports retain their original attribution.

The earlier preparation preservation readback found all 50 installed plugin files and 31 of 32 profile files byte-identical. The remaining profile index differed only in `Pages.Current`, its active-page selection; substituting only that field in memory reproduced its original hash. No button/dial settings changed. That preparation did not navigate Stream Deck or write profile files, and did not revert the externally changed active-page selection.

Mac mirror stop-time power changes/flashes and ON-without-output remain unresolved. Private mirror compensation is excluded; Windows Screen Mirror remains unsupported. Common startup/transport hardening does not certify mirror output or restoration.

The 2026-10-26 installation follow-up was initially recorded locally. Publication was separately approved on 2026-10-28 and incorporates those results into GitHub. Final-source/tag CI and download/readback gates still apply; passing earlier candidate CI is not substituted for them. Existing Mac installation/settings and earlier public assets are preserved. Mirror improvements and Marketplace submission remain on hold.
