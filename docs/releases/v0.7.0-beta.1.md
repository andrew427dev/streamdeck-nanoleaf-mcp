## Scope

- Recover last-command status across plugin-process restart without accepting stale results from a previous process.
- Add user-requested, read-only connection diagnostics and copying of a limited diagnostic summary. It reports only plugin/platform/validated MCP server and protocol versions, connection/capability indicators, supported-device count and safe errors; it neither launches Desktop nor changes lighting. The MCP server version is not labelled as the Desktop product version.
- Add Scene Browser long-touch refresh without playback. Preserve the selected name when it is still available and follow the dial's existing app-launch option. Short touch and dial press retain open/confirm behavior.
- Add a separate 0–100% Brightness Preset key while preserving existing action identifiers and saved settings. The default keeps an OFF light unchanged and displays a skipped result. Optional Apply uses one power-ON/brightness request for a positive value while OFF; 0% does not force ON.
- Clarify known mirror/brightness power side effects and distinguish published, installed and development verification states.
- Update SDK 3.0.5 / utils 0.7.0 / core 0.1.0 / schema 0.6.0, CLI 1.10.5, zip.js 2.25.0 and ws 8.23.0. Retain the scoped patched Zod 4.6.7 override because utils still declares the older range; compatibility and generated-license coverage remain mandatory.
- Pin CI action references and add one aggregate security/Mac/Windows success check. This CI job does not itself enable branch protection. Check version ordering against Git tags. Clean up this invocation's partial package output on caught write errors without overwriting earlier releases; forced kill/power-loss atomicity is not claimed.

The source is integrated and the final local suite passed. An older build's physical pass is not evidence for this candidate.
