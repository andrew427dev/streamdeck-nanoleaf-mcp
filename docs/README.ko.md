# Nanoleaf MCP for Stream Deck

Stream Deck에서 Nanoleaf Desktop의 전원·밝기·저장된 씬을 제어하는 macOS용 비공식 오픈소스 플러그인입니다.

[English](../README.md) · [릴리스](https://github.com/andrew427dev/streamdeck-nanoleaf-mcp/releases) · [개인정보 안내](../PRIVACY.md)

**v0.4.0-beta.1에는 클린 디자인, 제목에 맞춘 자동 배치, 읽기 쉬운 다이얼 아이콘이 추가되었습니다.** 기존 전원·밝기·터치 표시 전환·씬 탐색 기능은 유지합니다. macOS용 비공식 베타이며, 검증 범위는 아래에 안내합니다.

## 기능

### 클린 디자인과 제목에 맞춘 자동 배치

검정·민트의 클린 디자인을 적용하고 Stream Deck 기본 제목 설정에 맞춰 자동 배치합니다. 제목을 입력하면 공간을 남기고, 지우거나 **제목 표시**를 끄면 그래픽을 확대합니다. 전원·씬·밝기 키와 두 다이얼 모두 지원합니다. ON/OFF·밝기 수치·선택한 씬은 선택적인 제목과 별개로 유지됩니다. 사용자가 직접 지정한 아이콘은 플러그인 이미지보다 우선합니다.

제목 변경은 화면만 다시 그립니다. 조명 변경, 씬 탐색 초기화, 대기 중인 밝기 조절 취소, 동작 설정 저장은 하지 않습니다. 기본 제목의 글꼴·색 설정은 유지하며, 큰 제목으로 공간이 부족하면 이웃 씬보다 선택한 씬을 우선 표시합니다. 새 프로세스는 Stream Deck에서 제목 정보를 받을 때까지 안전한 제목 공간을 확보합니다.

Brightness Dial은 해 모양, Scene Browser는 목록·재생 모양을 사용하며 크기 비율과 중앙 정렬을 맞췄습니다. 공개판 카테고리에는 나노리프 공식 로고 대신 자체 제작한 빛기둥 모양을 사용합니다. 씬 화면의 **LAST APPLIED**는 마지막 실행 선택을 뜻하며, 현재 재생 상태를 실시간으로 확인했다는 의미는 아닙니다.

설치된 macOS 앱에서 제목 입력·삭제, Stream Deck 재시작 후 빈 제목의 확대 복원, 다이얼 아이콘 배치를 확인했습니다. 제목 표시 설정의 처리는 SDK 자동 테스트에도 포함됩니다. 실제 버튼·회전·터치 조명 제어와 앱 자동 실행은 이번 디자인 버전에서 다시 실물 검증하지 않았으며 제어 구현은 유지했습니다. 공개판 카테고리 아이콘은 기존 테스트 설치를 교체하지 않고 픽셀 테스트와 패키지 검사로 검증했습니다.

### 제어 동작

- **Power:** 선택한 장치의 전원을 켜거나 끄고, 현재 상태를 반전할 수 있습니다.
- **전원 상태 아이콘:** 켜짐은 민트색 ON, 꺼짐은 회색 OFF, 상태를 읽지 못하면 대시(—)로 표시합니다. 표시 중인 버튼·다이얼이 상태 조회를 공유하며 응답 후 약 2초마다 갱신합니다. 조회만으로 앱을 실행하지 않습니다. 사용자가 별도 아이콘을 지정하면 그 아이콘이 우선합니다.
- **Brightness Up / Down:** 밝기 증가·감소용 물리 버튼입니다. 기본값은 한 번에 5%p입니다.
- **Brightness Dial:** 돌리면 밝기 조절(기본 2%p), 누르면 전원 전환, 해당 터치 화면을 짧게 누르면 **막대 → 원형 → 큰 숫자** 표시 전환입니다. 표시 선택은 다이얼별로 저장되며 설정 화면에서도 선택할 수 있습니다. 조작하지 않을 때도 실제 상태가 갱신됩니다. 표시 전환 터치는 조명 변경이나 앱 실행을 하지 않으며, 회전·전원 누름은 자동 실행 설정을 따릅니다.
- **Scene Browser:** 두 번째 다이얼에 배치합니다. 처음 누르거나 터치하면 저장된 씬 목록을 열고, 돌려서 선택한 뒤 다시 누르거나 터치하면 실행합니다. 화면에는 현재 선택과 앞뒤 씬 이름을 보여줍니다. 선택만 바꿀 때는 조명을 변경하지 않습니다. 목록을 읽거나 실행 중일 때 중복 입력은 무시하며 실패한 명령을 자동 재전송하지 않습니다. 목록·선택은 메모리에만 보관하고 프로필에 저장하지 않습니다. 프로필을 나갔다 돌아오면 새 목록을 열 수 있습니다. 길게 터치하는 동작은 지정하지 않았습니다.
- 조작 성공 시 초록색 체크를 띄우지 않습니다. 실제 상태 표시, 오류 경고와 설정 화면의 실행 기록은 유지합니다.
- **Scene:** Nanoleaf Desktop에 이미 저장된 씬을 실행합니다.
- 버튼 설정의 드롭다운에서 장치와 씬을 선택합니다.
- 목록 새로고침 안내와 별도로 마지막 버튼 명령의 처리 중·성공·실패 원인을 설정 화면에 표시합니다.
- 조명 제어 또는 씬 목록 열기에 필요할 때 Nanoleaf Desktop을 실행하도록 설정할 수 있습니다. 기본값은 꺼짐이며 버튼·다이얼마다 따로 설정합니다. 밝기 표시를 바꾸는 터치로는 앱을 실행하지 않습니다.

밝기 조절은 설정에서 증감 폭을 1–100%p로 변경하고, 버튼 누르기·다이얼 회전 시 앱 자동 실행을 켤 수 있습니다. 밝기 증감은 0–100으로 제한하며 전원·씬 변경 명령은 보내지 않습니다. 밝기 다이얼 누름은 별도의 전원 전환 동작입니다. 같은 방향의 빠른 입력은 합치고, 방향을 바꾸면 순서를 유지합니다. 오류나 버튼 삭제·설정 변경 시 대기 입력을 폐기하며, 이미 전송한 명령은 재전송하거나 되돌리지 않습니다. 전원·씬과 밝기를 동시에 조작하면 처리 중인 장치에 대한 다른 명령은 안전하게 거절합니다.

플러그인은 같은 컴퓨터의 `http://127.0.0.1:15765/mcp`로 요청을 보냅니다. API 키나 유료 AI 서비스가 필요하지 않습니다. 설치 후 사용에는 별도의 헬퍼·단축어·Node.js 설치가 필요하지 않으며, Stream Deck에 포함된 실행 환경을 사용합니다. Nanoleaf Desktop 자체는 별도로 클라우드나 로컬 네트워크에 연결할 수 있습니다.

## 필요 환경과 호환성

- macOS 13 이상
- Stream Deck 7.1 이상
- 장치 연결과 설정이 완료된 Nanoleaf Desktop 3.x

이전 베타에서 장치·씬 목록, 조명 상태, 실제 전원·씬 버튼, 밝기 버튼·회전 조절과 설정 화면을 확인했습니다. v0.3.0-beta.1에서는 밝기 화면 터치·다이얼 전원 누름·씬 목록 열기와 회전 선택·터치와 누름 실행을 추가로 실물 검증했습니다. 검증 환경은 macOS, Nanoleaf Desktop 3.0.1, Stream Deck 7.6.0, Stream Deck +입니다. 앱이 완전히 종료된 상태에서의 자동 실행은 v0.3.0-beta.1에서 다시 시험하지 않았습니다. 이번 베타에서는 PC Screen Mirror Lightstrip(NL82K2)만 목록에 표시하며 제어를 지원합니다. 다른 장치와 이후 앱 버전의 호환성은 별도 검증이 필요합니다. 이번 버전은 Windows를 지원하지 않습니다.

## 설치와 버튼 설정

1. [릴리스 페이지](https://github.com/andrew427dev/streamdeck-nanoleaf-mcp/releases)에서 `io.github.andrew427dev.nanoleaf-mcp.streamDeckPlugin`을 받으세요.
2. 설치 파일을 두 번 클릭한 뒤 Stream Deck의 설치 안내를 따라 주세요.
3. Nanoleaf Desktop을 열고 앱에서 장치가 정상 작동하는지 확인해 주세요.
4. 원하시면 Stream Deck에 **Nanoleaf** 폴더를 만드세요. 폴더 안에서 **Nanoleaf MCP** 작업 분류의 **Power** 또는 **Scene**을 버튼에 끌어다 놓으세요.
5. 장치를 선택한 뒤 Power는 **On**, **Off**, **Toggle** 중 하나를, Scene은 저장된 씬을 선택해 주세요.
6. Stream Deck의 제목 입력란에 **ON**, **OFF** 또는 씬 이름을 적어 주세요. 버튼을 누르면 선택한 동작이 실행됩니다. 켜기·끄기 버튼과 씬별 버튼을 각각 만들 수 있습니다.

씬은 Nanoleaf Desktop에 저장된 것을 사용합니다. 플러그인에 씬 정의가 포함되어 있지는 않습니다. 설치 시 기존 헬퍼·단축어·버튼을 옮기거나 교체하지 않으므로, 기존 구성을 유지한 채 새 버튼을 시험하실 수 있습니다. 이번 버전은 플러그인·동작 식별자와 설정 형식을 유지하므로 버튼 배치, 선택 장치·씬, 밝기 조절 폭, 자동 실행, 제목 설정을 다시 구성할 필요가 없습니다. 업데이트 전 중요한 프로필은 내보내기로 백업하시고, 기존 플러그인이나 동작을 먼저 삭제하지 마세요.

### 밝기 버튼과 Stream Deck + 다이얼

1. 키에 **Brightness Down**, **Brightness Up**을 추가하고 장치와 밝기 증감 폭을 선택해 주세요.
2. Stream Deck +의 다이얼에 **Brightness Dial**을 추가해 주세요. 회전은 밝기 조절, 누름은 전원 전환, 바로 위 화면 터치는 막대·원형·숫자 표시 전환입니다.
3. 다른 다이얼에 **Scene Browser**를 추가하고 장치를 선택해 주세요. 처음 누르거나 터치해 목록을 열고, 돌려 선택한 다음 다시 누르거나 터치해 실행합니다. 터치는 강조된 씬을 실행하며, 화면에서 다른 줄을 직접 고르는 기능은 아닙니다.
4. 필요할 때 Nanoleaf Desktop이 열리도록 하려면 각 버튼·다이얼의 자동 실행을 켜 주세요. 꺼두면 앱이 이미 실행 중이어야 합니다. 설정 화면을 열거나 밝기 표시를 바꾸는 동작으로는 앱을 실행하지 않습니다.

## 문제 해결

- **버튼에 오류가 표시될 때:** Stream Deck에서 해당 버튼을 선택하고 설정 화면의 마지막 명령 상태를 확인해 주세요. 이 상태는 메모리에만 보관되어 플러그인을 다시 시작하면 초기화됩니다. 현재 조명의 실시간 전원 표시는 아닙니다.
- **연결되지 않을 때:** Nanoleaf Desktop을 열고 버전을 확인한 뒤 다시 시도해 주세요. 버튼별 자동 실행 옵션을 켜지 않았다면 앱이 실행 중이어야 합니다.
- **앱을 연 직후 처음 누를 때:** 자동 실행이 필요한 경우 앱 실행을 마친 뒤 장치 발견을 최대 15초 기다립니다. 전원 명령도 USB가 일시적으로 준비되지 않았다는 응답을 받으면 최대 10초 동안 상태를 확인합니다. 세션 만료로 거절된 읽기 요청은 한 번 재연결하며, 조명 변경 요청은 자동 재전송하지 않습니다.
- **장치나 씬이 없을 때:** Nanoleaf Desktop에서 연결 상태와 저장된 씬을 확인한 뒤 버튼 설정의 목록을 새로 고쳐 주세요.
- **운영체제의 권한 요청이 표시될 때:** Nanoleaf Desktop이 실제로 요청하는 권한을 확인하고 필요한 접근을 허용해 주세요. 시스템 전체의 보호 기능을 끄실 필요는 없습니다.
- **응답 시간이 초과될 때:** 요청이 이미 장치에 적용되었을 수 있습니다. 조명 상태를 확인한 뒤 다시 누르세요. 변경 요청을 자동 재전송하지 않습니다.
- **앱 업데이트 후 작동하지 않을 때:** 오류 보고에 앱과 플러그인 버전을 적어 주세요. 로그나 스크린샷을 첨부하기 전 장치 ID·씬 이름·개인 경로 등은 지워 주세요.

## 개발과 검증

개발 환경에는 Node.js 24와 npm을 사용합니다. 설치된 플러그인은 Stream Deck에 포함된 Node.js 24 환경에서 실행됩니다.

```sh
npm ci
npm test
npm run build
npm run validate
npm run pack
```

자동 테스트는 플러그인을 빌드한 뒤 합성 장치와 모의 응답을 사용합니다. 설치 파일의 동작 검사는 임시 로컬 WebSocket 서버를 사용하며 Nanoleaf 요청을 모두 가짜 응답으로 대체하므로 실제 조명을 변경하지 않습니다. 테스트나 패키지 검증을 통과했다고 실제 하드웨어 호환성까지 확인된 것은 아닙니다. 기여와 검증 기준은 [CONTRIBUTING.md](../CONTRIBUTING.md)에 안내되어 있습니다.

## 개인정보와 라이선스

장치 ID와 씬 이름은 Stream Deck의 로컬 버튼 설정에 저장됩니다. 내보낸 프로필에도 포함될 수 있으므로 공유 전 확인해 주세요. 자세한 내용은 [PRIVACY.md](../PRIVACY.md)와 [SECURITY.md](../SECURITY.md)를 참고해 주세요.
